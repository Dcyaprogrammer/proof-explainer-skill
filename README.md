# proof-explainer-skill

## Core concept

During my personal experience I find it nearly impossible to get LLM to give you the exact level of detail you need for proof. This can be relieved by providing context about your math capability, making it a non-general fix.

Thus this skill does not focus on teaching LLM to generate the "perfect" proof or explanation but teaching it to be a good tutor. It provides clear proof structure, intuitive explanation and critical steps and becomes ready for your follow-up questions.

The goal is that there's no logical gap but only computation gap where you can ask later to offer a smooth reading and understanding experience.
